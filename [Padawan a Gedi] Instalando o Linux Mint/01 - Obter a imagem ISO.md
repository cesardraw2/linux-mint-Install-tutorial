# 01 — Obter a imagem ISO

**Faça esta etapa no computador que está funcionando.** Ele pode ser Windows ou Linux. Você vai baixar a ISO para esse computador e depois usá-la para preparar o pendrive.

> [!tip] Um passo de cada vez
> Nesta etapa você só vai **baixar e conferir a ISO**. Ainda não reinicie o computador de destino e ainda não formate nenhum disco.

> [!warning] Baixe somente do site oficial
> Espelhos de terceiros e “ISO turbo” são o jeito mais comum de levar malware.

1. Abra [linuxmint.com/download](https://linuxmint.com/download.php).
2. **Cinnamon** é a edição recomendada para PCs modernos.
3. **Xfce** é a escolha certa para computador antigo ou com pouca RAM.
4. Pegue a ISO Standard 64-bit, com cerca de 3 GB.

## Escolha uma edição

### Cinnamon — recomendada

![[Anexos/edition-cinnamon.png]]

Visual moderno, efeitos leves e menu clássico. Melhor para a maioria dos alunos.

### Xfce — PC fraco

![[Anexos/edition-xfce.png]]

Leve e estável. Use se o notebook tem 4 GB de RAM ou GPU muito antiga.

### MATE — clássica

![[Anexos/edition-mate.png]]

Parecida com o GNOME 2. Boa se você já conhece esse desktop.
