# Cofre Obsidian — Instalar Linux Mint

Este diretório é um cofre Obsidian completo e independente, baseado no guia web do projeto.

## Como abrir

1. Abra o Obsidian.
2. Escolha **Abrir pasta como cofre**.
3. Selecione esta pasta `[Padawan a Gedi] Instalando o Linux Mint`.
4. Comece em [[Início]].

As caixas de seleção guardam o progresso no próprio arquivo Markdown. O [[Mapa do guia.canvas|Mapa do guia]] oferece uma navegação visual entre as etapas.

## Como ler sem se perder

1. Leia o bloco **Antes de começar** da nota.
2. Faça somente a ação indicada no próximo item.
3. Marque a caixa quando terminar.
4. Se aparecer **Pare**, não avance até confirmar a decisão.

O fluxo principal prepara a ISO, cria um pendrive e instala o Mint. Ele não substitui um tutorial específico de dual boot.
