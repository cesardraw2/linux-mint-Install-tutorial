# Cofre Obsidian — Instalar Linux Mint

Este diretório é um cofre Obsidian completo e independente, baseado no guia web do projeto.

## Como abrir

1. Abra o Obsidian.
2. Escolha **Abrir pasta como cofre**.
3. Selecione esta pasta `[Padawan a Gedi] Instalando o Linux Mint`.
4. Comece em [[Início]].

As caixas de seleção do Obsidian guardam o progresso no próprio arquivo Markdown. No guia web, o cenário escolhido e as tarefas marcadas ficam no `localStorage` do navegador. O [[Mapa do guia.canvas|Mapa do guia]] oferece uma navegação visual entre as etapas.

## Como ler sem se perder

1. Leia o bloco **Antes de começar** da nota.
2. Faça somente a ação indicada no próximo item.
3. Marque a caixa quando terminar.
4. Se aparecer **Pare**, não avance até confirmar a decisão.

O fluxo principal prepara a ISO, cria um pendrive e instala o Mint. O planejador filtra as etapas de acordo com o cenário escolhido, incluindo instalação limpa, dual boot, formatação de HD externo e teste em sessão live.

## Por que o guia é organizado por cenário?

Essa abordagem ajuda especialmente pessoas com TDAH e outras formas de neurodivergência porque reduz a carga cognitiva:

- mostra somente as tarefas relevantes para o objetivo escolhido;
- transforma o processo em passos curtos e concretos;
- indica claramente o que fazer agora;
- mantém o progresso visível e permite retomar de onde parou;
- evita decisões técnicas desnecessárias;
- alerta antes de ações destrutivas, como formatar um disco;
- deixa glossário e explicações acessíveis sem tirar o aluno da página.

O aluno não precisa montar mentalmente o próprio plano: o sistema organiza o caminho a partir do cenário escolhido. Os cenários e suas tarefas ficam documentados em [[BDD - Cenários de instalação|BDD - Cenários de instalação]], para edição e revisão no próprio cofre.
