# BDD — Planejamento por cenário

A especificação executável está em [`features/installation-scenarios.feature`](./features/installation-scenarios.feature).

O arquivo equivalente no cofre Obsidian é `BDD - Cenários de instalação.md`. Ele é a interface editorial para o aluno e alimenta o planejador do app; este documento e o `.feature` registram o mesmo comportamento em formato adequado para revisão e automação.

## Regra de manutenção

Ao adicionar um cenário, dê a ele um ID único `FC_MINT_Sxx`, inclua `Dado/Quando/Então`, descreva dados variáveis em `Esquema do Cenário` ou tabelas e replique as tarefas no arquivo do cofre. O código da interface não deve conter listas de tarefas fixas.
